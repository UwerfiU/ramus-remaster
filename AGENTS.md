# AGENTS.md — правила работы с репозиторием ramus-remaster

## Проект
- Форк Ramus — IDEF0/DFD моделлер на Java/Swing.
- Скоуп v0.1: только локальный редактор (без серверной части и сетевых фич).

## Сборка
- В начале каждой bash-сессии выполнить:
  `source /c/Users/123/Desktop/pet_projects/ramus_fork/env.sh`
- Затем компиляция: `./gradlew compileJava` (JDK 21 уже установлен).

## Референс оригинала
- Каталог `../ramus` — клон оригинального репозитория, используется только как референс.
- Изменять его запрещено ни в коем случае.

## Формат коммитов
- `"T<id>: краткое описание"`, где `<id>` — идентификатор задачи из
  `/c/Users/123/Desktop/pet_projects/ramus_fork/WORK_PLAN.md`.

## Ограничения на изменения кода
- Не менять и не форматировать код, не относящийся к текущей задаче.
- Совместимость формата файлов `.rsf` с оригиналом — жёсткое требование.
